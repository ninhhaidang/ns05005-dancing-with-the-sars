The entry **NISAR L-band Change Detection and Land Cover Mapping** (this website, the analysis and the code) was built by team **2936-ThanhNoi**, team ID **NS05005**, for the **NASA Space Apps Challenge 2026** challenge [Dancing with the SARs](https://www.spaceappschallenge.org/2026/challenges/dancing-with-the-sars/).

## Source code and data

- **Source code:** [github.com/ninhhaidang/ns05005-dancing-with-the-sars](https://github.com/ninhhaidang/ns05005-dancing-with-the-sars). It contains the Python scripts, the result figures and tables, and this website.
- **Data:** NISAR L2 GCOV (VALIDATED, CRID P05036) from the NASA ASF DAAC. The data is not stored in the repository; see [Reproduce](/reproduce/) for how to download and process it again.
- **Website:** [dwts.ninhhaidang.com](https://dwts.ninhhaidang.com), hosted on the team lead's home server.

## Acknowledgements

NISAR is a joint mission of NASA and ISRO; the data is distributed by the Alaska Satellite Facility DAAC. Sentinel-2 imagery (used only to draw training labels) is from ESA Copernicus. The web map base layer is OpenStreetMap (© OpenStreetMap contributors, ODbL).
